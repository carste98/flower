# Blombukett till Alva

En romantisk ensidig webbplats med en mer utvecklad bukett, körsbärsdetaljer och personlig hälsning till Alva.

## Starta

1. Öppna `index.html` i webbläsaren.
2. Klicka på **Låt Buketten Blomma** för att starta blomning och fallande kronblad.

## Anpassa

- Ändra namn och text i `index.html`.
- Justera färger och utseende i `styles.css`.
- Finjustera mängd och tempo för animationer i `script.js`.
